# 浏览器验收与交付

## 证据分类

| 类别 | 能证明 | 不能证明 |
| --- | --- | --- |
| 生成设计稿 | 视觉目标与构图 | 产品运行、交互或后台能力 |
| 真实运行截图 | 当时渲染、数据和状态 | 单靠截图不能证明按钮/接口有效 |
| 隔离状态示例 | 受控长内容/初始化等布局 | 真实模型输出或账号初始化 |
| 自动检查 | 已执行的构建、操作与断言 | 用户视觉接受、其他设备/付费服务 |

目录、文件名和图册标签注明来源。README 用真实运行截图展示产品，示例另列；不能用生成稿覆盖截图再写真实前端。

## 浏览器检查

采用可用的 Playwright、浏览器桥接或其他驱动，不依赖固定插件。启动项目真实 HTTP 服务与后端，确认 URL，不双击 React/Vite 入口 HTML。

按变更抽样检查：

- 参考视口的构图、侧栏、头像比例、图标、输入框和人物遮挡。
- 空白/有内容、代码/长文本、文件面板、表单、弹窗、错误与禁用。
- 移动窄屏、侧栏收起/抽屉、宽桌面及 200% 缩放。可抽样 320/390/768/1440 或已有断点，不规定固定套数。
- 导航、键盘焦点、Escape 返回、点击区域、滚动、输入和快捷入口，避免填草稿误变为自动发送。
- 主题切换、系统主题监听、减少动态；离线与加载按相关功能测试。
- pageerror、图片解码、404、横向溢出与受影响请求。

用现有测试账号、隔离环境或获准初始化流程。读操作和写操作分清：创建管理员、发消息、写工作区、付费调用需要相应授权，不重置现有后端为截图首次初始化。

等待字体与必要图片加载，固定视口和状态，减少动态。只读 fixture 响应注明来源，不拦截写操作制造保存成功；无真实模型/渠道凭据时保留未配置状态。

## 比较与修正

顺序为构图空间、材料外形、字体层次、状态响应。修正后重测受影响检查；纯素材替换无需写镜像实现的单元测试，认证/表单等行为修改需要有意义的回归。不要无理由重跑全部耗时测试。

## 图册与发布

需要双击图册时，做自包含静态页，分别展示设计、真实截图与素材，验证图片解码、放大和键盘关闭。应用继续通过 HTTP 启动，图册不是产品。

说明改了什么、为什么、实际构建/浏览器检查、未验证外部集成和待审阅图。不要发布账号、密钥或内部日志。

上传已授权时，核验目标仓库、隐私状态与分支，正常提交推送；只有当前提交的 CI 才能作为通过证据。不能自行公开私有项目，或从技能仓库许可证推导第三方图片的公开授权。
