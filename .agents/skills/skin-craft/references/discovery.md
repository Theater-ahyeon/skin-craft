# 灵感、素材发现与生图来源

没有参考图也能开始。先复用用户已提供的用途、项目与偏好；每轮只问会改变下一步的少量问题，不把素材、预算、设备、配色和角色问卷一次抛给用户。

## 把感觉变成可选方向

先弄清产品用途、是否需要人物、想要的情绪或体验。若用户只有“精美、特别、好看”，给两三个具体方向，各说明场景、材料、交互与取舍；这是可调整的起点。用户授权自主设计时选一个适合真实布局的方向继续。

从零开发且没有源码时，用一段短说明确定谁使用、核心操作、必要页面、数据如何读写和完成标准；不因选了美术方向就假定功能已定。把当前选择记在项目已有文档或简短设计记录中，便于下次接续，不另造规划系统。

| 方向示例 | 意象如何落到界面 | 需要平衡的点 |
| --- | --- | --- |
| 温柔手记 | 装订绳成为侧栏书脊，书签对应导航，来信纸承载回复 | 纸纹不能降低正文对比度 |
| 通透星夜 | 星轨连接会话，彗星对应发送反馈，冷暖双轨区分区域 | 保持文字稳定，限制闪烁与发光 |
| 工业终端 | 数据插槽导航、切角框、设备状态灯与附件卡匣 | 警示色只用于风险，避免满屏噪声 |
| 精致会客室 | 织物、缎带、刺绣与托盘边缘变成框体、导航和输入组件 | 花边与人物不抢占交互空间 |

从角色服饰、道具、环境和性格中选少量可辨识元素，映射到组件材料、轮廓和状态。某种作品风格不要求把全部人物塞进页面；去人物时保留环境、设备、配色和主题纹饰。任意主题都可采用这种转换，不固定为以上四种。

## 找图与整理参考

1. 先看附件与获准读取的本地素材；缺少时使用实际可用的图片搜索/浏览工具。按角色或题材、场景、材料与构图分别检索，不只找整页 UI 模板。
2. 展示少量有区分度的候选，说明各自负责人物身份、服饰、场景还是材质。遵守环境允许的图片预览方式；打不开的链接不当作已看过，不为绕过显示限制偷偷下载。
3. 保存作者/页面链接及已知使用条件。搜索结果可用于讨论，不自动成为可打包分发的资产。许可未确认的候选标为参考；正式素材按用户授权选自有图片、许可合适的图片或生图，AI 生成仍记录参考来源。
4. 视频/动态壁纸用已有工具查看代表帧，记录文件与时间点；先确认人物和场景，再考虑动效。源视频、预览缩略图与运行素材分别记录，不修改原 Wallpaper 目录。
5. 找不到合适参考或用户不想联网时，用文字方向生成探索稿。没有生图能力时可先做文字简报和构图说明，明确图片尚未生成。

短期签名 URL 不进入公开文档、运行依赖或日志。优先稳定来源与已授权本地副本；失效链接仅在阻塞看图时请求补图，其余工作继续。

## 选择实际可用的生图来源

首次需要生图且用户尚未选来源时，简短列出当前能用的路径及差异。可问：“使用当前内置生图，还是你指定的服务？”也允许用户在外部生成后交回素材。不要展示不存在的服务、模型或套餐。

| 路径 | 使用方式 | 需要明确的边界 |
| --- | --- | --- |
| 当前环境内置生图 | 默认推荐，按内置工具/技能调用 | 以实际参考图、透明输出与编辑能力为准 |
| 用户指定且可连接的服务 | 查官方调用说明，复用已有连接器/CLI | 服务选择、费用授权、参考图上传范围及凭据配置 |
| 用户外部生成后提供图片 | 提供同一简报、素材规格与逐项提示词 | 尚未拿到并检查图片时，只能称为提示词交付 |

用户选择“不指定/你决定”时优先内置路径，并说明采用的来源。已有选择持续有效，后续不逐图重问。等待选择时继续读源码和整理素材；需取得付费或外传授权的调用，等待回复后执行。

用户未要求选择来源，且当前请求和环境规则已允许直接生图时，说明采用的现有来源后继续，不把来源问答变成额外审批。明确要求自己选来源时保留该选择，不用默认值替用户提交。

所选来源不可用时，说明缺的是工具、连接、凭据还是功能；按环境生图规则处理备选路径。内置能力无需 API key 时不要求配置。不要索要聊天明文密钥、暗中切供应商、伪造请求记录或因本次设计安装整套新服务。

先生成代表性概念或关键素材，检查角色、构图、输出文件与透明能力，再展开整套素材。记录预期/实际尺寸、服务名及可分享回执；未返回的模型或请求 ID 标为未提供。只为需要比较的方向做变体，不无限批量出图。

## 进入实现或结束探索

有满意且可行的完整概念后，交给 [视觉契约](visual-contract.md) 固定人物与布局，再按 [素材规格](asset-prompts.md) 拆层。只要求概念图时交付可查看的图与说明；要求完整版则继续源码实现、真实浏览器验证和获准发布。

用户可以随时改变方向。记录当前选择、拒绝版本和下一步即可，不为每轮探索新建大型规划文档。
