# 零点契约案例

记录真实角色主题工作台改造的工程决策，不附私有账号、运行数据、壁纸或受限插画。

## 用户提供的概念设计过程

下表来自用户补充的过程描述，用于提炼方法；未在本次核验缺失的原始参考图或视频，也不把描述中的生图结果当作已验证的应用。两套《你的名字》、赛博朋克与视频参考阶段描述的是完整首页和三个控件细节，当时未修改 Demo。约一至六分钟的生图耗时是个人经历，不是交付时限；完整皮肤仍需后续开发与迭代。

| 过程 | 角色与视觉分工 | 可迁移的方法 |
| --- | --- | --- |
| Maid Atelier | 图 1、2 是两位不同女仆；图 3、4 可视为同一角色。两位女仆用于对话主体背景，Q 版可用于展开侧栏；没有确认就不推断 Q 版对应哪位女仆。 | 先明确身份关系和槽位，再生成完整概念图；选定满意且可实现的方案后，逐层拆成背景、侧栏、输入框、花边和动画，在真实 WebUI 中持续校正兼容性。 |
| 暮山·结缘手记 | 三叶与山夜黄昏的记忆意象；结绳装订侧栏、纸质书签导航、手记回复、绳结发送。 | 把角色故事转为材料、结构与动作语义，形成一套组件语言；不用角色大图承担全部定制。 |
| 星降·时空来信 | 泷与三叶、雪山星河与彗星相遇；双角色切换、蓝粉双轨导航、来信对话、彗星输入框。 | 同一作品可有两套独立构图与交互概念，分别记录各自的依据；角色切换等设计提案仍须核对真实宿主能力后实现。 |
| 夜之城·潜网终端 | 初稿有露西身份卡、单分子线连接轨道、数据插槽导航，以及大卫黄夹克快速模式和残影构想；后来用户要求去除人物，转为设备、芯片与快速模式。 | 角色删除只更新相关槽位，保留雨夜城景、青蓝碳黑终端、切角装甲输入框、数据分片附件槽与黄色发送；红色集中用于风险提示。认可的功能结构不必随人物一起推倒。 |
| 视频到零点契约 | 用户描述以本地 30 秒路鸣泽视频为参考：礼服翻领侧栏、私人契约簿、四分契约印、黑金邀约函、冰蓝宝石附件、酒红封蜡发送、契约文书回复与纹样风险提示。 | 将视频中的服装、物件、姿态和紫蓝天台气氛分别映射到静态组件；实际使用视频时记录选用帧与时间点。保留乌鸦、黄金瞳和克制金光的层次，不把单一画面全部压进每个控件。 |

这些角色和命名只说明设计来源，不作为下一项目默认题材，也不证明素材已获公开分发授权。用户的点子、满意选择与外部反馈决定方向，生成服务和源码实现负责将其变成可审阅结果。

## 参考各司其职

图二主导人物、夜城、黑金材料与全幅空白首页；图一提供已有消息后的文件树和配置工作区。概念板下方的组件说明没有成为产品主页。

页头 66px、桌面侧栏 288px 是该案例的选择，其他项目从自己的参考测量。组件语言覆盖智能体、能力、任务、记忆和设置，不只美化首页。

## 原图与否定反馈

用户否定早期河岸城市人物图，后来指定原始夜城图统一所有背景。运行图无损编码，3840×2160 解码 RGBA 相同；页面通过裁切/蒙层适配。尊重最新直接选择，不把再生图当作所有问题的答案。

## 高度定制的部件

最初采用折面皮革、纹章、金圈头像、酒红选中与羊皮纸乌鸦区。五个导航功能分别生成封蜡、卷轴、书册、羽毛笔和星盘，检查展开、收起及移动抽屉的实际尺寸。头像是当时的设计选择，后续宿主皮肤按用户要求移除，不是每套侧栏的固定部件。

输入框拆为材料、斜角金边、蓝宝石、羽毛和发送封蜡，输入与按钮继续用真实组件。无字金色 logo 单独生图，页头、登录、加载、应用图标共源，产品名称由 DOM 排版。

## 失败与验证

一次故障来自转发器保留压缩响应却按 JSON 解码；在授权范围内修复协商/解压/请求体保留后，原生生图成功。它不授权下个项目修改代理，也不是通用故障原因。

前端保留真实认证、权限、Agent/Workspace/Session、REST/WebSocket 与文件链路。无模型配置显示空状态；隔离示例与实际运行截图分开，图册可双击，应用经 HTTP 启动。

背景像素、浏览器操作、构建和用户视觉接受分别记录。产品改名后重新采集实际截图，内部 API/存储键保持兼容。

## 反馈、宿主适配与回退

| 实际反馈或变更 | 后续处理应保留的经验 |
| --- | --- |
| 左上角不要头像，品牌应为 `Deepseek Harness` | 更新相应结构与 DOM 文案；重新分配腾出的侧栏空间，保持用户指定的大小写，不沿用概念图中的旧品牌。 |
| “工作区”文字错位、设置图标与乌鸦重叠 | 从文字基线、控件盒与装饰保护区找原因；在展开、收起、移动抽屉中复查，装饰位置与真实点击区域分别验证。 |
| 自主美化后用户认为没有之前好，要求回退 | 以最后认可的视觉版本为基准恢复受影响资产和样式；先看差异，保留无关的功能修复，不用整仓重置完成局部回退。 |
| 从工作台迁移到 DSH 创意工坊 | 遵循目标宿主的主题接口、脚手架与贡献规范，重新采集真实会话及要求的设备/主题截图；原应用通过不等于移植版本通过。 |
| 来源声明与 CI 成为收录阻塞 | 如实记录 AI 生成分类、可核验记录、许可范围及缺失证据；生成经历不等于版权核验。对无关测试超时核对提交和日志，在授权与权限内有限重跑，不把旧提交通过写成当前提交通过。 |

每轮只记录“反馈、受影响组件、修改、同状态截图、接受或回退”。外部建议先与当前认可的构图核对，用户未确认的新方案保持可回退；自动检查不能代替人的视觉判断。
